# Charts

This subdirectory records the structure and provenance of the attached paper chart bundle (`Charts (2).zip`).

`SOURCE_REFERENCE.txt` is copied from the attachment and maps each chart to the result files from which its numbers/time series were obtained. `manifest.json` records the complete attached file list, including the with-values / without-values SVG sets and endpoint power time-series charts.

The attached bundle contains generated SVGs plus a very large `chart_v2.py`. Those generated artifacts are analysis outputs rather than experiment configuration. The authoritative final paper configuration is therefore kept separately under `../configuration/` so older source-archive names in the chart bundle cannot be confused with the final 6×5 evaluation setup.

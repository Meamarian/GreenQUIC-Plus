Controlled-loss notes for T8
============================

This suite does not execute tc/netem automatically because it generally requires
administrator privileges and the correct Linux interface must be selected.

Example only (run on the intended path/interface after review):

    sudo tc qdisc add dev <iface> root netem loss 0.1%
    # run the test
    sudo tc qdisc del dev <iface> root

Prefer deterministic loss bursts or several fixed loss rates (0, 0.1, 0.5, 1%).
Always record the exact command, interface, direction, kernel version and qdisc
statistics. Never leave the qdisc installed after the experiment.
